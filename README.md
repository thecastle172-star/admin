# لوحة إدارة قلعة عقارات الدورة

واجهة إدارة عربية مبنية بـ React وTypeScript وVite. تشمل لوحة رئيسية وإدارة كاملة للعقارات والبنرات وإعداد رقم واتساب، مع تصميم متجاوب للهاتف.

## التشغيل

```bash
npm install
npm run dev
```

## التحقق

```bash
npm run build
npm run lint
```

العقارات والبنرات والإعدادات متصلة بمشروع Convex. الصور تُختار مباشرة من الجهاز، ثم تُصغّر مع الحفاظ على النسبة، وتتحول إلى WebP قبل رفعها إلى Convex Storage. تبقى نسخة محلية احتياطية لواجهة الإدارة.

مفتاح الإدارة وبيانات النشر محفوظة في `.env.local` المتجاهل من Git. لا تنشر لوحة الإدارة للعامة قبل استبدال مفتاح التطوير بنظام تسجيل دخول للمستخدم الإداري.
