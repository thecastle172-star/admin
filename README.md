# لوحة إدارة قلعة عقارات الدورة

واجهة إدارة عربية مبنية بـ React وTypeScript وVite. تشمل لوحة رئيسية وإدارة كاملة للعقارات والبنرات وإعداد رقم واتساب، مع تصميم متجاوب للهاتف.

## التشغيل

```bash
npm install
npm run dev
```

## التحقق

```bash
npm run build
npm run lint
```

البيانات محفوظة حاليًا في `localStorage` على الجهاز نفسه. مزامنة التعديلات مع تطبيق المستخدم تحتاج ربط المشروعين بقاعدة Convex في مرحلة لاحقة.
